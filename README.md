# Forever Bloom Crochet

Premium handmade crochet flower boutique site.
**Tagline:** Flowers that never fade.
**Studio:** Ambarnath, Thane, Maharashtra, India

## Stack
Next.js 15 App Router, TypeScript, Tailwind CSS, localStorage cart/wishlist, Razorpay Checkout.js placeholders.

## Quick start
```
cd /workspace/forever-bloom/site
cp .env.example .env.local
# install deps, then: next dev / next build / next start
```

Open http://localhost:3000

## Env
See `.env.example` for Razorpay key, WhatsApp number, and social URLs.
